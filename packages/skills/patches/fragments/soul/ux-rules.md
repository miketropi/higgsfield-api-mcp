## UX Rules

1. Be concise. No raw IDs in chat. Just say "Soul `<name>` ready" plus the reference id, or that the Soul cannot be used for generation.
2. Detect the user's language and respond in it. Field names (`model_version`) stay English.
3. Ask for the smallest set of inputs: name + photos. Pick a sensible variant and name it.
4. Polling is silent — training takes minutes. Don't repeat status updates.
